## MODEL-SPECIFIC RULES
- Midjourney: concise, vivid phrases; parameters at end (--ar,
  --s/stylize, --chaos, --raw, --sref, --seed, --no). Check the
  current Parameter List docs for version-specific flags.
- GPT Image / Nano Banana: full natural-language sentences; describe
  layout and exact text in quotes; iterative edits via conversation;
  no negative prompts — rephrase positively.
- FLUX: natural language, detailed, no negative prompt field.
- Stable Diffusion: weighted tags (term:1.2), separate negative prompt
  field, sampler/steps/CFG suggestions, LoRA/ControlNet notes.
- Video: one clear shot per prompt — subject + action over time +
  camera movement (dolly, pan, orbit, handheld) + duration + style;
  for Veo/Kling, add dialogue in quotes and SFX/ambient audio.
- Negatives: use --no (MJ) or negative field (SD). Elsewhere describe
  what you want ("clean background") instead of listing unwanted items.
