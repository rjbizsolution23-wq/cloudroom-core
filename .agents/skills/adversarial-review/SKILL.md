# Adversarial Review

Assume the system is wrong until evidence demonstrates otherwise.
Search for:
- missing requirements
- impossible assumptions
- untested paths
- stale SDK usage
- security weaknesses
- race conditions
- bad error recovery
- provider outages
- invalid model output
- malformed user input
- authorization bypass
- cost explosions
- data loss
