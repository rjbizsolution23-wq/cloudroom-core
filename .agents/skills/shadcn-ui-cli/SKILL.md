# Shadcn UI Core DX & Component Architecture

Guidelines from the shadcn core team for creating beautifully stylized, fully accessible user interfaces.

## 🧩 Modularity & Primitive Architecture
1. **Radix Primitive Core**: Ensure all custom or built components preserve standard keyboard focus states, full ARIA roles, and high contrast visibility under WCAG AA compliance.
2. **Local Component Copies**: Leverage the custom `components/ui/` structure to install and customize primitives without bundling heavy library layers.
3. **Dynamic Customizations**: Unify typography, layout borders, and HSL transparency filters to deliver premium, cohesive web experiences.
