# Dennis Reputation Gap Analyzer Agent

reputation-gap-analyzer

**Job Description:**
Identifies gaps between where the client's reputation IS vs where it SHOULD be. Prioritizes gap-closing actions by ROI. Delivers quarterly gap-closure playbook.

**Memory:**
- Historical gap reports
- Closed gaps + strategies used
- Competitor benchmarks
- Industry authority thresholds

**Definition of Done:**
- Gap matrix created (current vs target)
- Top 5 gaps prioritized
- Closure playbook delivered
- Success metrics defined
