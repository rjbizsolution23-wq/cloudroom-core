## 1. CONVERSATIONS LAYER (SIGNAL 2026, May 6–7, San Francisco) ✅
═══════════════════════════════════════════════════════════════
GA at SIGNAL: Conversation Orchestrator, Conversation Memory, Conversation Intelligence,
Enterprise Knowledge API, Twilio Agent Connect.
All Conversations products appear ONLY in the new Console (`1console.twilio.com`). Accounts not
yet migrated get redirected to the legacy Console, where these products don't exist.

**Conversation Orchestrator** ✅
- Observes Voice, SMS, and WhatsApp traffic and links interactions into one conversation per
  customer profile. Coordinates routing and handoffs between human and AI agents.
- Configure in Console or via API. Docs: `twilio.com/docs/conversations/orchestrator`
- Conversation Metadata: GA (Sep 27, 2026).
- ⚠️ Exact REST paths (e.g. `conversations.twilio.com/v2/...`): confirm in the API reference.

**Conversation Memory** ✅
- API base: `https://memory.twilio.com` | Auth: Basic (`AccountSid:AuthToken`)
- Memory stores, identity-resolved profiles, traits/identifiers (structured facts),
  observations/summaries (unstructured), and a token-efficient Recall for LLM context.
- NOT HIPAA eligible and NOT PCI compliant. Do not use it in HIPAA or PCI workflows.
- Not intended for sensitive personal data. Profiles are generated by AI; review them for errors.
- Subject to Twilio's Predictive and Generative AI/ML Features Addendum.
- Segment → Conversation Memory integration: GA (Oct 5, 2026). Two modes: "Memory Sync" (full
  profile import) and "Memory Destination" (audience-targeted sync); trait updates flow in real time.
- Studio widgets "Resolve Profile" and "Create or Update Profile": available (Sep 24, 2026).
- Docs: `twilio.com/docs/conversations/memory` | `twilio.com/docs/api/memory/v1`

**Conversation Intelligence** ✅
- Prebuilt and custom LLM "operators" analyze live interactions: sentiment shifts,
  escalation flags, actions triggered mid-conversation.
- On-demand rule execution: GA (Sep 27, 2026).
- ⚠️ Custom operator endpoint (`intelligence.twilio.com/v3/ControlPlane/Operators`): verify.
- Note: "Conversation Intelligence (classic)" is a separate, older product. Don't mix them up.

**Enterprise Knowledge API** ✅ GA. Knowledge bases built from websites, text, or uploaded files.
- ⚠️ Website crawl depth and auto-update options: verify in docs.

**Twilio Agent Connect (TAC)** ✅ GA, open source
- Python: `github.com/twilio/twilio-agent-connect-python` (includes a setup wizard: `make setup`)
- TypeScript: `github.com/twilio/twilio-agent-connect-typescript` | npm `twilio-agent-connect`
  - Requires Node.js 22.13.0 or newer.
  - Channels: Voice (via ConversationRelay), SMS, RCS, WhatsApp, Chat. Supports multiple sender numbers.
  - Outbound conversations, a ConversationRelay-only mode, automatic Memory integration,
    and human handoff via Studio Flows (including Flex).
  - Examples: OpenAI, WhatsApp, Chat, relay-only, OpenAI Realtime over Media Streams,
    GPT-Live over Media Streams, outbound, voice call events (answering-machine detection,
    recording, call disposition), voice DTMF.
  - TELEMETRY IS ON BY DEFAULT. It sends account SID, channel, conversation ID, and timings
    (no message content). Disable with `TAC_ANALYTICS_DISABLED=true`.
- AWS package: `github.com/twilio/twilio-agent-connect-aws` (Strands, Bedrock Agents, AgentCore)
- Microsoft package: `github.com/twilio/twilio-agent-connect-microsoft` (Agent Framework,
  Azure AI Foundry incl. Voice Live, Azure OpenAI)

**Other SIGNAL 2026 launches** ✅

## 7. COMPLIANCE GUARDRAILS (always on)
═══════════════════════════════════════════════════════════════
- AI-generated voices are "artificial" under the TCPA (FCC 24-17). Outbound AI calls need prior
  express consent and the TCPA/TSR disclosures. Never write outbound dialers without a consent check.
- HIPAA: use only HIPAA-eligible products (e.g. ConversationRelay), with a signed BAA.
  Conversation Memory is excluded.
- PCI: never let card numbers or security codes reach LLM prompts, transcripts, or recordings.
  Use Twilio's PCI-compliant paths (e.g. `<Pay>`, ⚠️ verify current docs).
- Recording consent varies by US state (one-party vs all-party). Disclose and record consent.
- EU: use the IE1 region where available (SMS, Short Codes, TaskRouter/Studio beta),
  and document which products don't support it.
