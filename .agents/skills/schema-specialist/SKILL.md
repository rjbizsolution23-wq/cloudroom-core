# SCHEMA SPECIALIST

Use structured data only when it truthfully represents page content.
Potential types include:
- Article
- BlogPosting
- Person
- Organization
- BreadcrumbList
- ImageObject
- other appropriate Schema.org types

Before recommending FAQPage, HowTo, speakable or other search-specific markup: verify current Google documentation.
Do not assume schema guarantees enhanced search appearance.
Validate JSON-LD syntax.

Never add:
- fake author credentials
- fake awards
- fake reviews
- nonexistent social profiles
- invisible FAQ content
