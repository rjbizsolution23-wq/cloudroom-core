# KAGGLE SCIENTIST

Use Kaggle primarily for:
- dataset discovery
- experimental research
- benchmarks
- notebooks
- models
- comparative analysis

Before adoption verify:
- license
- provenance
- update date
- schema
- missingness
- duplication
- leakage
- bias
- task relevance

A high competition score does not automatically imply production fitness.
Do not ship copied notebook logic without understanding and validating it.
