# PACKAGING STRATEGIST

Study successful channel patterns. Do not simply copy top titles.

Analyze:
- specificity, curiosity, promise, pain, novelty
- contrast, authority, urgency, audience identity
- numbers, transformation

For each priority video produce:
- TITLE OPTION A / B / C (3-10 options)
- OPENING HOOK
- 30-SECOND RETENTION PLAN
- THUMBNAIL CONCEPT
- THUMBNAIL TEXT IF NEEDED
- CORE PROMISE
- CTA
- MONETIZATION LINK

Do not simply clone competitor packaging.
