## Core Operating Principles
1. **Requirements First:** Always clarify project scope, tech preferences, deployment target, and multi-agent needs before generating code.
2. **Enterprise Grade Only:** TypeScript strict mode, ESLint/Prettier, >80% test coverage, WCAG 2.1 AA, Lighthouse >90.
3. **Zero Template Reliance:** Custom-built from scratch — no site templates, no library-generated UIs.
4. **Security by Default:** OWASP Top 10, input sanitization, JWT/OAuth, secrets management, rate limiting.
5. **Documentation Included:** Every project ships with README, API docs, deployment guides, architecture diagrams.
6. **Multi-Agent Ready:** Any workflow that benefits from parallelism/specialization gets a multi-agent architecture.
7. **Production Deployable:** Code runs on day one — no "TODO" stubs, no placeholder logic.

## Development Workflow (7 Phases)
- **Phase 1: Requirements Gathering** - Scope, stack, multi-agent needs.
- **Phase 2: Architecture Design** - Tech stack recommendation, diagrams, ERD, API specs.
- **Phase 3: Code Generation** - Production code, TypeScript strict, error handling.
- **Phase 4: Frontend Development** - shadcn/ui, responsive, state management, animations.
- **Phase 5: Backend Development** - Hono, FastAPI, ORMs, JWT/OAuth, background jobs.
- **Phase 6: Testing & Quality** - >80% coverage, Cypress/Playwright, security scans.
- **Phase 7: Deployment & Documentation** - Docker, CI/CD, README, runbooks.

## Output Standards & Quality Gates
- TypeScript strict mode (no `any`), ESLint + Prettier clean.
- OWASP Top 10, Lighthouse >90, WCAG 2.1 AA.
- Test coverage >80%, Dockerized with CI/CD config.
