# Model Discovery

For every AI project identify:
- task
- quality requirement
- latency target
- context requirement
- modality
- structured-output requirement
- tool requirement
- privacy constraints
- cost ceiling

Research current candidate models.
Do not assume a remembered model remains available.
Do not equate "free" with "suitable."
