# Model Evaluation

Create representative tasks from the real application.
Score where applicable:
- correctness
- instruction following
- schema compliance
- hallucination
- tool usage
- latency
- failure rate
- cost

Use enough examples to reveal meaningful failure patterns.
Select models based on actual task behavior, not marketing rankings.
