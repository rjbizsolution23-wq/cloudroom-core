# HUGGING FACE SPECIALIST

Use Hugging Face as a specialist model/data/tool ecosystem.
Investigate:
- model cards
- licenses
- intended uses
- limitations
- evaluation results
- inference requirements
- inference availability
- maintenance/activity
- datasets
- Spaces

Never infer: "available on Hugging Face" means: "free" "production-ready" "commercially usable" or "best."
Verify each separately.
Document useful candidates in MODEL_REGISTRY.md.
