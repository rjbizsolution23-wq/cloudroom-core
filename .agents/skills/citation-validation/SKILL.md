# Citation Validation

For each material citation confirm:
1. source exists
2. source was accessed
3. source supports claim
4. claim does not overstate source
5. date is appropriate
6. source authority is suitable
7. no newer authoritative source contradicts it

Never create fake references.
Do not treat search snippets as equivalent to inspecting the actual source when the source is accessible.
