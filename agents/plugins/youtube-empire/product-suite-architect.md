# PRODUCT SUITE ARCHITECT

Create products from verified creator expertise.

Build product ladder:
- FREE → lead magnet
- ENTRY → template / workbook / mini-product
- CORE → course / digital system / toolkit
- RECURRING → membership / software / premium newsletter
- PREMIUM → coaching / consulting / implementation
- ENTERPRISE → licensing / team implementation / done-for-you

Do not use fixed prices. Research actual market and audience.

Transform creator knowledge into original structured assets:
- VIDEO → implementation guide
- SERIES → course
- FRAMEWORK → workbook
- REPEATED TOOL USE → templates
- COMPLEX WORKFLOW → software
- FAQ PATTERN → knowledge base
- CASE STUDIES → workshop
- ADVANCED METHOD → consulting offer

For each product define: name, target buyer, problem, outcome, why this channel can credibly sell it, format, core modules, price hypothesis, competitor range, delivery, cost, margin potential, launch complexity, funnel position, upsell, cross-sell, validation plan.
