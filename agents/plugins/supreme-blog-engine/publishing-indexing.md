# PUBLISHING & INDEXING

Verify current search-engine documentation before recommending indexing actions.
Check:
- status code
- canonical
- robots directives
- sitemap inclusion
- internal discovery links
- mobile rendering
- page performance
- metadata
- structured data

Do not assume historical ping endpoints still exist.
Do not promise immediate indexing.
Do not claim an indexing request guarantees indexing.

Prepare publication actions but require authorization before modifying a live site or submitting external actions.
